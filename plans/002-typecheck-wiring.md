## Why this matters

The repo has TypeScript `strict` plus `noUnusedLocals`/`noUnusedParameters` in
`tsconfig.app.json`, but its strictest gate is the LAST thing anyone runs:
`pnpm check` (what AGENTS.md tells contributors and agents to run before a PR)
does format + lint + dash-check and never typechecks. The dedicated
`pnpm typecheck` (`tsc -b`) fails on a fresh checkout because
`src/routeTree.gen.ts` is gitignored and only generated by `vite build` /
`vite dev`. Net effect: type errors are routinely discovered one CI round-trip
after push instead of in 0.7 seconds locally.

Repo conventions: user-visible strings Serbian, comments English, em dash /
en dash / Unicode minus FORBIDDEN everywhere (AGENTS.md) - plain ASCII `-` only,
including in this repo's config and docs you will edit.

## Steps

### Step 1: Add `@tanstack/router-cli` and its config

`pnpm add -D @tanstack/router-cli` (the repo convention is floating `latest`
ranges - keep whatever specifier `pnpm add` writes, do not pin it).

Create `tsr.config.json` at the repo root, mirroring the vite plugin options:

```json
{
  "routesDirectory": "src/routes",
  "generatedRouteTree": "src/routeTree.gen.ts"
}
```

**Verify**: `pnpm exec tsr generate` -> exit 0 and `src/routeTree.gen.ts` exists.

### Step 2: Prove the CLI output matches the vite plugin output

This is the load-bearing check. Run:

```bash
pnpm exec tsr generate && shasum src/routeTree.gen.ts
pnpm build >/dev/null 2>&1 && shasum src/routeTree.gen.ts
```

Compare the two hashes. Semantically-equivalent formatting differences are
acceptable ONLY if `tsc -b` passes on the CLI-generated file; byte-equality is
the clean pass.

**Verify**: second `pnpm build` exits 0 AND `pnpm exec tsr generate && pnpm exec tsc -b` exits 0. If `tsc -b` fails on the CLI-generated tree, this is a STOP condition (use the fallback below).

### Step 3: Rewire the scripts

In `package.json`:

```json
"typecheck": "tsr generate && tsc -b",
"check": "oxfmt --check && oxlint --deny-warnings && pnpm run check:dashes && pnpm run typecheck",
```

**Verify**: `rm -f src/routeTree.gen.ts && pnpm typecheck` -> exit 0 and the file is regenerated; `pnpm check` -> exit 0.

### Step 4: Update AGENTS.md

In the "Ostalo" bullet about lint/build, replace the claim that `tsc -b` cannot
run without a prior build with the new reality: `pnpm typecheck` regenerates
the route tree itself (via `tsr generate`) and `pnpm check` now includes it.
Keep the note that CI's `pnpm build` step remains the authoritative
build+typecheck. Write it in Serbian, matching the file's tone, ASCII hyphens
only.

**Verify**: `pnpm run check:dashes` -> exit 0 (AGENTS.md is exempt from the dash check, but your edit must not introduce forbidden characters elsewhere anyway).

### Step 5: Full gate

**Verify**: `pnpm check && pnpm test && pnpm build` -> all exit 0. `git status` shows only in-scope files changed (plus the still-ignored `src/routeTree.gen.ts`).
